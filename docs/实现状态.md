## 怎么划分

审核分两条**独立**通道，各自产出问题、取并集；本轮只做通道①：

| | 通道 ① 解析通道 | 通道 ② 渲染通道 |
|---|---|---|
| 输入 | `.docx`（OOXML） | 学生本机导出的 `.pdf` |
| 读什么 | 文档的**声明**：有效格式 / 样式 / 结构 / 域 / 页面设置 | 文档的**实际版面**：几何 / 分页 / 真实字形 |
| 能判 | 字体 / 字号 / 加粗 / 对齐 / 缩进 / 行距 / 页眉页脚 / 顺序 / 表格边框 | 分页位置 / 跨页 / 超出版心 / 页码连续性 / 行数溢出 |
| 本轮 | ✅ 做 | ⏸ 未纳入（不引入 PDF / 几何） |

落到规则上：

- **通道①的规则**：全部实现（字体、缩进这些以 docx 声明为准，见 `规则/README.md`）。
- **通道②的规则**：需要“排完版才知道”，本轮不做 → 目前只有 `TXT-50`（续表是否跨页）。
- **内容 / 著录格式类**：无法可靠判定，本轮不做 → `REF-16 ~ REF-20`（参考文献著录骨架）。

> 「不做 ≠ 不提」：见文末「未覆盖声明」，报告里会显式列出，避免“没报 = 肯定没问题”。

## 未覆盖声明（`UNCOVERED`）

以下事项**不实现**，但会在报告里显式声明（`report/issues.py` 的 `UNCOVERED`）：

- 分页与页码的实际版面效果：本工具只检查文档结构里的分页标记，最终效果以打印或 PDF 为准。
- 目录页码的正确性 / 连续性 / 一致性（需要渲染后的页面结果）。
- 跨页表格的续表标注（需要知道表格实际是否跨页）。
- 参考文献著录格式的标点校验（本期不做）。

## 一致性怎么保证

`tests/rules/test_rule_ids.py` 用三条硬断言锁死「文档 ↔ 代码」：

```
代码注册 − 文档            == ∅   # 代码不能有文档没有的
代码注册 ∩ EXCLUDED        == ∅   # 代码不能实现“本期不做”的
(文档 − EXCLUDED) − 代码注册 == ∅   # 文档在范围内的一条都不能漏
```

也就是说：**改规则前先改文档**；`docs/规则/*.md` 是规则号的权威来源。
