## 对象与识别

| 对象 | 识别方式 |
|---|---|
| ABSTRACT 标题 | 可见文本**忽略大小写、去掉内部空白后**等于 `ABSTRACT` |
| 英文摘要正文 | 英文摘要区内、标题之后、Keywords 行之前的**非空段落**（可多段） |
| Keywords 行 | 英文摘要区中以 `Keywords`（忽略大小写）开头、后跟冒号的行，**以冒号（含）为界**切分 |
| Keywords——前缀 | Keywords 行中冒号（含）之前的部分 |
| Keywords——内容 | Keywords 行中冒号之后的部分 |

> **识别锚点要宽松**（见 README「通用判定口径」第 7、8 条）：标题按"忽略大小写、去空白后等于 `ABSTRACT`"匹配，冒号全 / 半角都先认下；写错由文本规则报，只有**完全识别不到**才是"缺失"（`ABS-E-22`）。

## 规则详情

### ABS-E-01 · 文本

- **对象**：ABSTRACT 标题
- **期望**：`ABSTRACT`（**全大写**）
- **判定**：可见文本逐字符比较
- **说明**：识别锚点须**宽松**（忽略大小写），否则学生写成 `Abstract` 时会变成"找不到英文摘要"，而不是报出本规则

### ABS-E-02 · 西文和数字字体

- **对象**：ABSTRACT 标题
- **期望**：Times New Roman
- **判定**：`ABSTRACT` 全是 ASCII 字符，读有效格式的 `ascii` 槽
- **说明**：规范样张里该 run 只写了 `eastAsia=宋体`，`ascii` 槽继承 `Normal` 样式的 Times New Roman —— **不要看 run 自身属性**

### ABS-E-03 · 字号

- **对象**：ABSTRACT 标题
- **期望**：三号 = 16pt

### ABS-E-04 · 加粗

- **对象**：ABSTRACT 标题
- **期望**：加粗

### ABS-E-05 · 对齐

- **对象**：ABSTRACT 标题
- **期望**：居中

### ABS-E-06 · 后空行

- **对象**：ABSTRACT 标题段之后
- **期望**：正好 1 个空段落
- **判定**：空段落 = 段落内无文字、无图片、无域结果

### ABS-E-07 · 西文和数字字体

- **对象**：英文摘要正文
- **期望**：Times New Roman
- **判定**：按**字符**定位——只判 ASCII 字母与数字，读其所在 run 的有效 `ascii` 槽；**排除标点**

### ABS-E-08 · 字号

- **对象**：英文摘要正文
- **期望**：小四 = 12pt

### ABS-E-09 · 行距

- **对象**：英文摘要正文
- **期望**：1.5 倍
- **判定**：`lineRule=auto` 时倍率 = `w:line / 240`

### ABS-E-10 · 首行缩进

- **对象**：英文摘要正文
- **期望**：2 字符
- **判定**：优先读 `w:ind/@firstLineChars`（1/100 字符）；缺失时用 `@firstLine ÷ 字号` 换算

### ABS-E-11 · 后空行

- **对象**：英文摘要正文最后一段之后
- **期望**：正好 1 个空段落

### ABS-E-12 · 文本

- **对象**：Keywords——前缀
- **期望**：`Keywords：`（`K` 大写；冒号为**全角冒号**）

### ABS-E-13 · 西文和数字字体

- **对象**：Keywords——前缀
- **期望**：Times New Roman

### ABS-E-14 · 字号

- **对象**：Keywords——前缀
- **期望**：小四 = 12pt

### ABS-E-15 · 加粗

- **对象**：Keywords——前缀
- **期望**：加粗
- **说明**：前缀加粗、内容不加粗，必须**按行内片段**分别判定

### ABS-E-16 · 西文和数字字体

- **对象**：Keywords——内容
- **期望**：Times New Roman

### ABS-E-17 · 字号

- **对象**：Keywords——内容
- **期望**：小四 = 12pt

### ABS-E-18 · 行距

- **对象**：Keywords——内容
- **期望**：1.5 倍

### ABS-E-19 · 首行缩进

- **对象**：Keywords——内容
- **期望**：2 字符
- **判定**：同 ABS-E-10，优先 `@firstLineChars`

### ABS-E-20 · 分隔符

- **对象**：Keywords——内容
- **期望**：关键词之间用**中文分号** `；`
- **判定**：按 `；` 切分，若出现空段或发现其他分隔符（`;` `,` `、`）则报出

### ABS-E-21 · 末尾标点

- **对象**：Keywords——内容
- **期望**：末尾**无标点**
- **判定**：最后一个字符若属于标点则报出

### ABS-E-22 · 存在性

- **对象**：英文摘要区
- **期望**：必须存在 **Keywords 行**（以 `Keywords` 开头 + 冒号）
- **判定**：按宽松锚点（文本以 `Keywords` 开头，**忽略大小写**，后跟冒号）查找；**找不到**即报出
- **报告口径**：`未识别到 Keywords 行，请检查是否按「Keywords：…」形式书写`
- **说明**：只判"有没有"，不判格式——冒号、加粗、分隔符由 `ABS-E-12~21` 判；识别宽松（`keywords:`、半角冒号都先认下）

## 不做

| 项 | 原因 |
|---|---|
| Keywords 换行时续行与第一个关键词首字母对齐 | "是否换行"在解析通道只能估算，已定不做 |
| 摘要字数 ≤250 个实词 | 规范写了，但属内容规则 |
| ABSTRACT 标题的行距 | 规范未要求 |
| 英文摘要正文、Keywords 的对齐 | 规范未要求 |
| Keywords 个数 | 规范只对中文关键词写了 3–5 个 |

## 来源说明

- **规范文字里有**：标题「"ABSTRACT"用三号、Times New Roman、居中，加粗；标题与正文之间空一行」；正文「小四号、Times New Roman，行间距 1.5 倍行距，首行缩进 2 字符」；Keywords「和正文之间空一行，小四号、Times New Roman，加粗，行间距 1.5 倍行距，首行缩进 2 字符；关键词之间用分号相隔。如需换行，则新行与第一个关键词首字母对齐」；「英文摘要一般不超过 250 个实词」
- **取自规范样张**：标题居中、标题后 1 个空段落；Keywords 用中文分号 `；`
- **外部标准**：无
