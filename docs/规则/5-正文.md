## 对象与识别

| 对象 | 识别方式 |
|---|---|
| 一级标题 | 大纲级别 1 级；可见文本以 `第…章` 开头 |
| 二级标题 | 大纲级别 2 级；可见文本以 `N.N` 开头 |
| 三级标题 | 大纲级别 3 级；可见文本以 `N.N.N` 开头 |
| 三级以下标题 | 可见文本以 `（1）` `（2）` … 开头 |
| 正文段落 | 正文区内、不属于以上任何标题、不属题注、不属表格的非空段落 |
| 引用标注 | run 级属性 `w:vertAlign="superscript"` |
| 公式 | 段落中的 `w:object`（MathType OLE）或 `m:oMath`（OMML） |
| 公式段落 | **独占一行**的公式对象：段落里除对象外没有中文正文（行内公式、整段「式中…」说明算正文） |
| 公式单元 | **相邻的**公式段落合并成一个单元（跨行公式，或「公式 + 式中说明」共用 1 个编号） |
| 公式编号 | 公式段落文本中的 `(数字-数字)`，如 `(3-1)` |
| 图 | 段落中的 `w:drawing` |
| 图题 | 可见文本匹配 `^图\d+-\d+` 且**不是句子**（不含 `。；！？`）的段落 |
| 表题 | 可见文本匹配 `^表\d+-\d+` 且不是句子的段落 |
| 续表 | 可见文本匹配 `^续表\d+-\d+` 且不是句子的段落 |

**标题层级必须用大纲级别 / 样式名判，不能用字号或加粗猜。**

> **存在性识别要宽松**（见 README「通用判定口径」第 7、8 条）：`TXT-51` 按文本 `第…章` 收集一级标题，**不依赖大纲级别**；级别写错由识别之外的规则报，只有**完全识别不到**才是"缺失"。

## 规则详情

### TXT-01 · 文本

- **对象**：一级标题
- **期望**：`第` + 中文数字 + `章` + **2 个半角空格** + 标题
- **判定**：可见文本逐字符比较
- **说明**：识别锚点须**宽松**，否则空格写错会变成"找不到标题"

### TXT-02 · 中文字体

- **对象**：一级标题
- **期望**：黑体

### TXT-03 · 字号

- **对象**：一级标题
- **期望**：三号 = 16pt

### TXT-04 · 对齐

- **对象**：一级标题
- **期望**：居中
- **来源**：规范文字未写，取自 `heading 1` 样式（样张里一级标题居中）——**已定：查**

### TXT-05 · 行距

- **对象**：一级标题
- **期望**：1.5 倍

### TXT-06 · 后空行

- **对象**：一级标题段之后
- **期望**：其后正好 1 个空段落
- **判定**：空段落 = 段落内无文字、无图片、无域结果

### TXT-07 · 另起一页

- **对象**：一级标题
- **期望**：从第二章开始，每章另起一页
- **判定**：规范样张用**分节符**实现（不是 `w:pageBreakBefore`），须同时认**分节符**与**分页符**
- **边界**：**第一章**的另起一页属 `9-整体` 的 `GLB-22`（正文模块独立起页）；本规则只管**第二 ~ 第五章**

### TXT-08 · 文本

### TXT-09 · 中文字体

### TXT-10 · 字号

- **对象**：二级标题

### TXT-11 · 西文和数字字体

### TXT-27 · 字号

- **对象**：正文段落
- **期望**：小四 = 12pt

### TXT-28 · 首行缩进

- **对象**：正文段落
- **期望**：2 字符
- **判定**：优先读 `w:ind/@firstLineChars`
- **说明**：「首行缩进 2 字符」与「小四下缇值 480」视觉等价 → 视为通过

### TXT-29 · 行距

- **对象**：正文段落
- **期望**：1.5 倍
- **来源**：规范对正文只写了"小四号宋体，外文选用 Times New Roman，每段首行缩进 2 字符"，**未写行距**；1.5 倍取自样张——**已定：查**

### TXT-30 · 上标

- **对象**：引用标注
- **期望**：上标
- **判定**：run 有 `w:vertAlign="superscript"`

### TXT-31 · 字体

- **对象**：引用标注
- **期望**：Times New Roman，小四
- **依据**：规范原文"参考文献的引用，小四号 Times New Roman 字体，上标"

### TXT-32 · 编号格式

- **对象**：公式单元
- **期望**：**每个公式都要有编号**；编号为 `(章号-序号)`，**半角圆括号**、中间半角 `-`
- **判定**：**相邻的公式段落合并成一个公式单元**；单元内任一段文本匹配 `\((\d+)-(\d+)\)` 即合规；**找不到编号即报出「公式缺编号」**
- **说明**：一个公式常被拆成多段对象——跨行公式，或「公式 + 式中说明」（样张 3.2 节的「式中：z₀为…」就是裹在 Equation 对象里的说明，与公式**共用 1 个编号**），合并成单元后不应各算一个公式；**行内公式**（段落里还有中文正文，如「其中，μ 为…」）属正文，不算公式段落。`[数字]` 之类的引用括号**不算**公式编号。规范原文"所有的公式要有公式号"

### TXT-33 · 对齐

- **对象**：公式段落（单元里带编号的那些段）
- **期望**：居中
- **判定**：公式单元里带编号的段落有效 `jc=center`；单元完全没编号则判首段
- **依据**：规范原文"公式号和公式一起要居中对齐"
- **样张实测**：带编号的公式段落 `jc=center` → 合规；相邻的「式中说明」不参与

### TXT-34 · 编号字号

- **对象**：公式编号
- **期望**：五号 = 10.5pt（`w:sz=21`）
- **样张实测**：编号 run 未写 `sz`，继承 `Normal` 的 `sz=21` → 合规

### TXT-35 · 编号字体

- **对象**：公式编号
- **期望**：Times New Roman
- **判定**：只判编号里的 **ASCII 字母与数字**（如 `3-1`），读其所在 run 的有效 `ascii` 槽；**排除括号与 `-` 等标点**
- **样张实测**：`3-1` 所在 run 未写 `rFonts`，继承 `Normal` 的 `ascii=Times New Roman` → 合规

### TXT-52 · 编号正确性

- **对象**：公式编号
- **期望**：
  - **章号** = 公式**所属一级标题**的章号（中文数字 → 阿拉伯数字）
  - **序号** = 该公式在本章内的次序，**从 1 起连续，不跳号、不重复**
- **判定**：按一级标题把公式分章；章号不符报出；每章内序号集合须恰为 `{1, 2, …, N}`（`N` = 本章公式数）
- **说明**：规范原文"公式序号按一级标题编排，如一级标题是第三章，公式为该级标题的第 1 个公式，则为 3-1，依次类推"

### TXT-36 · 必须有引用

- **对象**：公式
- **期望**：正文中出现该公式号的引用
- **判定**：在**非公式段落**的正文里查找 `式(n-m)` 或 `(n-m)`
- **样张实测**：正文「由式(3-1)给出：」→ 合规
- **依据**：规范原文"在文中出现的公式一定要有引用"

> **公式对象**：规范样张用的是 **MathType OLE**（`w:object` + `ProgID="Equation.3"`），**不是 OMML**；本模块两种都认（`w:object` 或 `m:oMath`）。

### TXT-37 · 编号格式

- **对象**：图题
- **期望**：`图` + 章号 + `-` + 序号，如 `图3-1`

### TXT-38 · 位置

- **对象**：图题
- **期望**：图题在图的**下方**
- **判定**：比较**最近的图对象**在题上方还是下方——上方更近（或下方没有图）即合规；上方没有图则报出
- **说明**：图位 = 含图（`w:drawing`）的块。浮动图（`wp:anchor`）与图题之间常夹着空段或轴标注文字（样张里的「i(t)」），只按「紧邻上一块」会把合规的图题误判成「题在图上方」

### TXT-39 · 对齐

- **对象**：图题
- **期望**：居中
- **来源**：规范原文"放在图位下方居中处"——**以规范为准**（样张为两端对齐，属样张自身偏差，不作为判定依据）

### TXT-45 · 对齐

### TXT-49 · 三线表

- **对象**：表格
- **期望**：只有上框线、下框线、表头下框线，**无竖线与内横线**
- **判定**：按 `tcBorders` > 行 > `tblBorders` > 表格样式条件格式的优先级；`w:sz` 单位为 1/8 pt

### TXT-50 · 续表标注

- **对象**：跨页表格
- **期望**：续表在右上方标 `续表X-Y`

### TXT-51 · 存在性

- **对象**：正文的一级标题
- **期望**：`第一章` `第二章` `第三章` `第四章` `第五章` **五章齐全**
- **判定**：按**宽松锚点**（文本以 `第…章` 开头）收集一级标题，检查 `一`~`五` 是否都在
- **报告口径**：`未识别到第X章，请检查章节标题写法`
- **说明**：
  - 只判"**有没有**"，不判标题文本 / 字体 / 字号——那些由 `TXT-01~07` 判
  - 允许有第六章及以后（只要求 `第一~第五章` 存在），**不判是否恰好五章**
  - 识别宽松：`第一章 引言`、`第 一 章`、`第1章` 都先认下，文本写法错误由 `TXT-01` 报
  - 「正文」整个模块缺失（连第一章都没有）归 `9-整体` 的 `GLB-26`

## 不做

| 项 | 原因 |
|---|---|
| 正文不少于 8000 字 | 内容规则 |
| 续表（跨页表格）的格式：标注 / 位置 / 对齐 | 需知道表格是否实际跨页，属通道 ②；`TXT-50` 本期不做，`续表` **不套用普通表题规则**（TXT-43/44/45/46/47） |
| 插图必须手绘、不得截图 | 无法判定 |
| 量的单位符合法定计量单位 | 内容规则 |
