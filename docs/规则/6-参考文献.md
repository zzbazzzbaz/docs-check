## 对象与识别

| 对象 | 识别方式 |
|---|---|
| 参考文献标题 | 可见文本**去掉内部空白后**等于 `参考文献`；样张中大纲级别为 1 级（`heading 1`） |
| 参考文献区 | 从参考文献标题之后，到「致    谢」标题之前（**致谢标题不属于本区**） |
| 文献条目 | 参考文献区内、标题之后的**非空段落** |
| 空段落 | 段落内无文字、无图片、无域结果（bookmark / 批注锚点不算内容） |
| 文献类型标识 | 条目文本中**题名之后**的方括号字母（`[M]` `[J]` `[N]` `[D]` `[EB/OL]`） |
| 著录字段 | 以类型标识为分界：其前为「责任者.题名」，其后为各类型特有字段 |
| 正文引用 | 正文的引用标注（上标），见 `5-正文` 的 `TXT-30 / TXT-31` |

> **条目识别要宽松**：条目 = 区内的非空段落，**不要求以 `[数字]` 开头**。编号写错时必须由 `REF-10` 报错，而不是变成"找不到条目"（见 README「识别锚点要宽松」）。
>
> **边界说明**：模板里的「注意：1、不同类型文献的标识不同……」是**浮动文本框**，不是正文段落，不算条目；若学生把它粘成正文段落，会被 `REF-10 / REF-21` 报出——属预期（规范不允许说明文字出现在参考文献区内）。

## 文献著录格式

### 依据

- **结构依据**：**GB/T 7714-2015《信息与文献 参考文献著录规则》**（现行国标）
- **标点依据**：**学校自己的约定**（全角 `，` `：` + 半角 `.` `( )`），与国标示例的半角标点略有差异
- **判定依据**：**规范样张里学校给出的 5 条示例**

> 结论：按 GB/T 7714-2015 的**结构**校验，标点按**学校约定**校验（**已定**，不采用国标半角）。

### 学校标点约定

| 位置 | 标点 |
|---|---|
| 责任者之间 | 全角 `，` |
| 责任者与题名之间 | 半角 `.` |
| 文献类型标识之后 | 半角 `.` |
| 出版地与出版者之间 | 全角 `：` |
| 出版年与页码之间 | 全角 `：` |
| 出版者（或刊名）与出版年之间 | 全角 `，` |
| 年与卷之间 | 全角 `，` |
| 卷与期之间 | 半角 `( )` |
| 报纸名与出版日期之间 | 全角 `，` |
| 报纸版次 | 半角 `( )` |
| 著录末尾 | 半角 `.` |

### 字段切分

对每个条目：

1. 取出**可见文本**（排除域代码 `w:instrText`），去掉首尾空白
2. 用 `^\[(\d+)\]\s?` 切出**编号**（`REF-10` 负责判其格式）
3. 在正文部分里找到**类型标识** `[字母…]`，其**前**是「责任者 + `.` + 题名」，其**后**是各类型特有字段
4. 责任者部分**本轮不校验**；其余交给对应 `REF-16~20`

### 五类骨架（取自学校示例）

| 类型 | 骨架 | 学校示例 |
|---|---|---|
| 书籍 `[M]` | `责任者.题名[M].出版地：出版者，出版年：页码.` | `[1] 严蔚敏，吴伟民.数据结构[M].北京：清华大学出版社，1997：35-37.` |
| 期刊 `[J]` | `责任者.题名[J].刊名：分辑，年，卷(期)：页码.` | `[2] 王伟国，刘永萍，王生年，等.B/S模式网上考试系统分析与设计[J].石河子大学学报：自然科学版，2003，6(2)：145-147.` |
| 报纸 `[N]` | `责任者.题名[N].报纸名，出版日期(版次).` | `[4] 邓辉.校训雷同，缺失是什么?[N].光明日报，2013-03-06(08).` |
| 学位论文 `[D]` | `责任者.题名[D].保存地：保存者，年份：页码.` | `[5] 张磊.基于Internet的远程控制计算机网络实验系统[D].大连：大连海事大学，2012：113.` |
| 电子文献 `[EB/OL]` | `责任者.题名[EB/OL]. [引用日期].URL.` | `[3] 张美金.基于ASP技术的远程教育系统体系结构的研究[EB/OL]. [2003-05-01].http://172.50.0.88:86 /~cddbn/Y517807/pdf/index.htm.` |

> 骨架里的字段都可缺省，但**分隔符只要出现就必须正确**：例如 `[M]` 无页码时可以没有「出版年：页码」，但只要有「出版地、出版者」，就必须是全角 `：` 连接。分辑（如"自然科学版"）可有可无；有则与刊名之间用全角 `：`。

## 规则详情

### REF-22 · 存在性

- **对象**：参考文献区（「参考文献」标题之后、「致    谢」之前）
- **期望**：必须至少有 **1 条文献条目**（区内非空段落）
- **判定**：统计区内的非空段落数；**为 0** 时报出
- **报告口径**：`未识别到参考文献条目，请检查是否按「[1] 作者.题名[M]…」形式书写`
- **说明**：
  - 只判"有没有条目"，不判编号 / 字体 / 著录格式——那些由 `REF-06~20` 判
  - 识别宽松：即使编号写错、类型标识写错，只要**有非空段落**就算"存在"（写成 `1. 作者…` 也先认下，由 `REF-10` 报编号错误）
  - 「参考文献」模块整个缺失（连标题都没有）归 `9-整体` 的 `GLB-26`

### REF-01 · 文本

- **对象**：参考文献标题
- **期望**：`参考文献`，**中间不加空格**
- **判定**：可见文本逐字符比较；识别锚点放宽为「去空白后等于 `参考文献`」，否则学生写错时会变成"找不到标题"
- **来源**：规范文本框在此处只标了「一级标题」（含义见 REF-02）。样张标题为 `参考文献`（**无空格**）
- **说明**：与 `摘    要` / `目    录` / `致    谢` / `附    录` 不同——这四个在样张里都有 4 个空格，**只有参考文献不加空格**。规范文本框附近另有「空1格」标注，含义不明、样张未体现，**不据此判定**

### REF-02 · 中文字体

- **对象**：参考文献标题
- **期望**：黑体
- **来源**：规范文本框「一级标题」+ 规范另处定义"一级标题：黑体，三号"

### REF-03 · 字号

- **对象**：参考文献标题
- **期望**：三号 = 16pt
- **来源**：同上

### REF-04 · 对齐

- **对象**：参考文献标题
- **期望**：居中
- **来源**：样张标题用 `heading 1` 样式（`eastAsia=黑体`、`sz=32`、`jc=center`、`outlineLvl=0`）

### REF-05 · 后空行

- **对象**：参考文献标题段之后
- **期望**：正好 1 个空段落
- **判定**：空段落 = 段落内无文字、无图片、无域结果
- **依据**：规范文本框「空1行」；样张标题后恰有 1 个空段落

### REF-06 · 中文字体

- **对象**：文献条目（逐条检查）
- **期望**：宋体
- **判定**：只判**中文字符**所在的 run，读其**有效 `eastAsia` 槽**；纯西文 run 不判中文字体
- **样张实测**：中文 run 显式写了 `ascii=宋体` 但**没写 `eastAsia`**，`eastAsia` 继承 `Normal` 的宋体 → 合规

### REF-07 · 西文和数字字体

- **对象**：文献条目（逐条检查）
- **期望**：Times New Roman
- **判定**：
  1. 「字母、数字」= **ASCII 字母 `A–Z a–z` 与数字 `0–9`**，**不含标点**（`. , ? ( ) / : - [ ]` 等排除）
  2. 对每个字母 / 数字字符，读其所在 run 的**有效 `ascii` 槽**（run → 字符样式 → 段落样式链 → `Normal` → `docDefaults` → 主题），要求 = Times New Roman
- **为什么排除标点**：规范原文只说"字母、数字"；且样张里 `.` `?` 等标点所在 run 的 `ascii` 槽是 `宋体`，把标点算作西文会**误报学校自己的样张**
- **样张实测**：`[1]` `[M]` `1997` `35-37` `http://…` 所在 run **未写 `rFonts`**，继承 `Normal` 的 `ascii=Times New Roman` → 合规；「大连海事大学，」run 写了 `ascii=Arial`，但内容**全是中文字符、不含字母数字** → 不判，合规。**若按段落级字体判定会误报**

### REF-08 · 字号

- **对象**：文献条目（逐条检查）
- **期望**：小四 = 12pt（`w:sz=24`）

### REF-09 · 行距

- **对象**：文献条目（逐条检查）
- **期望**：1.5 倍
- **判定**：`lineRule="auto"` 时倍率 = `w:line / 240`（`360 → 1.5`）
- **样张实测**：条目的 `pPr` 为 `spacing line="360" lineRule="auto"`，无 `pStyle`（继承 `Normal`） → 合规
- **注意**：`lineRule` 为 `exact` / `atLeast` 时排版行为不同，**直接报出**

### REF-10 · 编号格式

- **对象**：文献条目
- **期望**：`[1]` `[2]` …，数字用**半角方括号**，编号与内容之间正好 **1 个半角空格**
- **判定**：可见文本匹配 `^\[(\d+)\]( ?)(\S)`，检查括号与空格数
- **拒绝**：全角方括号 `［］` / `【】` / `()`；编号后 0 个或 ≥2 个空格；全角空格 `U+3000`；制表符；前导零 `[01]`
- **边界**：编号必须是**手打文字**；条目段落用了 Word 自动编号时由 `GLB-28` 报出，**本规则与 `REF-11` 均不重复报**（见 README「通用判定口径」第 10 条）
- **样张实测**：`[1] ` 后恰好 1 个半角空格
- **与 REF-21 不重叠**：本规则只判「**以某种括号 + 数字开头**、但格式 / 空格写错」的情形；段落**完全不以编号开头**时由 `REF-21` 报，本规则**不重复报**

### REF-11 · 编号连续性

- **对象**：全部文献条目
- **期望**：从 1 开始，逐个递增，**不跳号、不重复**
- **判定**：条目编号集合必须恰为 `{1, 2, …, N}`（`N` = 条目数）。跳号、重复、缺号分别报出
- **不做**：自动"排序修复"。本规则只报事实，不改写

### REF-12 · 文献类型标识

- **对象**：文献条目
- **期望**：类型标识**只能是五类之一**——`[M]` `[J]` `[N]` `[D]` `[EB/OL]`
- **判定**：
  - 题名之后**没有**类型标识 → 报出
  - 有标识但**不在五类之内**（`[C]` `[P]` `[S]` `[A]` `[Z]` `[M/OL]` `[J/OL]` `[DB]` …）→ **报出**（本轮只认这五类）
  - `[数字]` 编号不算类型标识
- **说明**：`[EB/OL]` 作为整体匹配，`[M]` 等单字母需与 `[数字]` 编号区分开。规范「注意」第 1 条即"不同类型文献的标识不同"，第 3 条列举了 `[M/OL]` `[J/OL]`——本轮按学校示例**收窄为这五类**
- **不做**：「选得对不对」（如期刊该用 `[J]`）需语义判断，交给 `REF-16~20` 从骨架侧面兜

### REF-13 · 重复条目

- **对象**：文献条目
- **期望**：同一条文献只出现一次
- **判定**：条目文本（去掉编号与首尾空白后）**完全一致**时判为重复
- **说明**：规范原文"同一文献出现多次，只用同一标号"——指**正文里重复引用同一文献时应复用同一编号**（属正文引用问题）。本规则只兜"参考文献表里同一条列了两遍"
- **不做**：近似重复（作者 / 题名相同但标点或空格不同）需相似度判断，**不做**

### REF-21 · 段落完整性

- **对象**：参考文献区的非空段落
- **期望**：一条文献占且仅占 **1 个段落**
- **判定**：
  - 区内**完全不以编号开头**的非空段落 → 报出（疑似被拆段 / 混入说明文字）
  - 条目段落内出现手动换行 `w:br` → 报出
- **说明**：允许一条文献因排版自然折行（自动换行不是 `w:br`，不报）

### REF-14 · 正文引用

- **对象**：文献条目 × 正文引用
- **跨作用域**：需要 `5-正文` 的引用标注（上标 `[数字]`）才能判；正文抽取失败时按“无法判定”处理
- **期望**：每条文献都在正文中被引用过
- **判定**：取正文所有引用标注的编号集合 `C`，与条目编号集合 `R` 比对：
  - `R \ C`（有条目、正文没引用）→ **本规则报出**
  - `C \ R`（正文引了不存在的编号，"悬空引用"）→ 属正文 / 整体作用域，本规则不报
- **无法判定**：若正文区抽取失败或引用标注无法识别 → 显式输出「无法判定」，**不静默通过**
- **说明**：规范原文"所有参考文献必须都在正文中有引用"

### REF-15 · 引用顺序

- **对象**：文献条目
- **跨作用域**：同 `REF-14`，依赖 `5-正文` 的引用标注
- **期望**：按在正文中**出现的先后次序**排列
- **判定**：按正文引用**首次出现**的顺序排出编号序列 `S`，与 `1…N` 比对；出现倒置即报出首个倒置位置
- **无法判定**：同 REF-14，抽不到引用顺序时显式输出「无法判定」
- **说明**：规范原文"按在正文中出现的先后次序列于此处"

### REF-16 · 书籍 `[M]` 著录格式

- **骨架**：`责任者.题名[M].出版地：出版者，出版年：页码.`
- **检查**：
  - 责任者与题名之间为**半角 `.`**
  - 类型标识 `[M]` 之后紧跟**半角 `.`**
  - 存在 `出版地：出版者`，分隔符为**全角 `：`**，且出版地、出版者均非空
  - 出版者与出版年之间为**全角 `，`**
  - 若有页码，出版年与页码之间为**全角 `：`**
  - 条目以**半角 `.`** 结尾
- **不检查**：作者姓名对错、题名与文献是否匹配、年份页码真假

### REF-17 · 期刊 `[J]` 著录格式

- **骨架**：`责任者.题名[J].刊名：分辑，年，卷(期)：页码.`
- **检查**：
  - `[J]` 之后紧跟**半角 `.`**
  - 刊名非空；有分辑时与刊名之间为**全角 `：`**
  - 刊名（或分辑）与年之间为**全角 `，`**
  - 年与卷之间为**全角 `，`**
  - 卷与期用**半角 `( )`**，且期号非空
  - 期与页码之间为**全角 `：`**
  - 条目以**半角 `.`** 结尾
- **说明**：分辑（如"自然科学版"）可有可无

### REF-18 · 报纸 `[N]` 著录格式

- **骨架**：`责任者.题名[N].报纸名，出版日期(版次).`
- **检查**：
  - `[N]` 之后紧跟**半角 `.`**
  - 报纸名非空；报纸名与日期之间为**全角 `，`**
  - 日期形如 `YYYY-MM-DD`
  - 版次用**半角 `( )`**，如 `(08)`
  - 条目以**半角 `.`** 结尾

### REF-19 · 学位论文 `[D]` 著录格式

- **骨架**：`责任者.题名[D].保存地：保存者，年份：页码.`
- **检查**：
  - `[D]` 之后紧跟**半角 `.`**
  - 保存地与保存者之间为**全角 `：`**
  - 保存者与年份之间为**全角 `，`**
  - 年份与页码之间为**全角 `：`**
  - 条目以**半角 `.`** 结尾

### REF-20 · 电子文献 `[EB/OL]` 著录格式

- **骨架**：`责任者.题名[EB/OL]. [引用日期].URL.`
- **检查**：
  - `[EB/OL]` 之后紧跟**半角 `.`**
  - 其后 1 个**半角空格** + 引用日期，形如 `[YYYY-MM-DD]`
  - 引用日期之后为**半角 `.`** + 访问路径（`http://` 或 `https://`）
  - 条目以**半角 `.`** 结尾
- **URL 判定**：URL 内允许空格与任意字符（样张 `http://172.50.0.88:86 /~cddbn/Y517807/pdf/index.htm` 就含空格），不做 URL 合法性校验
- **说明**：规范原文"电子文献还包括 `[M/OL]`、`[J/OL]` 等类型，请根据具体参考资料情况选择"。本轮只做 `[EB/OL]`；`[M/OL]` `[J/OL]` 由 `REF-12` 报为"类型不在五类内"

## 不做

| 项 | 原因 |
|---|---|
| 参考文献不少于 10 篇 | 内容规则 |
| 最好为近十年研究成果 / 外语专业以外文文献为主 | 内容规则 |
| 文献类型标识"选得对不对" | 需语义判断 |
| 其他文献类型（`[C]` `[P]` `[S]` `[A]` `[Z]` `[M/OL]` `[J/OL]` `[DB]` …）的**骨架** | 只认五类；出现即由 `REF-12` 报出，不做骨架校验 |
| 条目内各字段的**内容**（作者姓名、题名、年份、页码的真伪） | 需外部知识 |
| 条目的**对齐**（样张为左对齐）、**首行 / 悬挂缩进**（样张无缩进） | 规范未要求；以学校样张为准，本轮不判 |
| 条目之间的**空段落** | 规范未要求 |
| 参考文献标题内的空格 | 规范标注与样张不一致（见 REF-01），不判 |
| 参考文献单独起页 | 属「9 整体」作用域，已登记为 `GLB-23`（本轮纳入） |
