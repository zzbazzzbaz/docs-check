## 对象与识别

| 对象 | 识别方式 |
|---|---|
| 中文摘要标题 | 可见文本**去掉内部空白后**等于 `摘要` |
| 中文摘要正文 | 中文摘要区内、标题之后、关键词行之前的**非空段落**（可多段） |
| 中文关键词行 | 中文摘要区中以 `关键词` 开头、后跟冒号的行，**以冒号（含）为界**切分 |
| 中文关键词——前缀 | 关键词行中冒号（含）之前的部分 |
| 中文关键词——内容 | 关键词行中冒号之后的部分 |

> **识别锚点要宽松**（见 README「通用判定口径」第 7、8 条）：标题按"去空白后等于 `摘要`"匹配，冒号全 / 半角都先认下；写错由文本规则报，只有**完全识别不到**才是"缺失"（`ABS-C-25`）。

## 规则详情

### ABS-C-01 · 文本

- **对象**：中文摘要标题
- **期望**：`摘    要`（「摘」与「要」之间**正好 4 个半角空格**）
- **判定**：可见文本逐字符比较
- **说明**：识别锚点须**宽松**（按"去空白后等于 `摘要`"匹配），否则学生把空格数写错时会变成"找不到摘要标题"，而不是报出本规则

### ABS-C-02 · 中文字体

- **对象**：中文摘要标题
- **期望**：黑体

### ABS-C-03 · 字号

- **对象**：中文摘要标题
- **期望**：三号 = 16pt

### ABS-C-04 · 对齐

- **对象**：中文摘要标题
- **期望**：居中

### ABS-C-05 · 后空行

- **对象**：中文摘要标题段之后
- **期望**：正好 1 个空段落
- **判定**：空段落 = 段落内**无文字、无图片、无域结果**

### ABS-C-06 · 中文字体

- **对象**：中文摘要正文
- **期望**：宋体
- **判定**：逐段检查；只判**中文字符**所在的 run，读其有效 `eastAsia` 槽

### ABS-C-07 · 西文和数字字体

- **对象**：中文摘要正文
- **期望**：Times New Roman
- **判定**：按**字符**定位——只判 ASCII 字母与数字，读其所在 run 的有效 `ascii` 槽；**排除标点**
- **说明**：中文 run 里写 `ascii=宋体` 只对该 run 里的西文字符才有影响；若该 run 不含西文，不算违规

### ABS-C-08 · 字号

- **对象**：中文摘要正文
- **期望**：小四 = 12pt

### ABS-C-09 · 行距

- **对象**：中文摘要正文
- **期望**：1.5 倍
- **判定**：段落的有效行距。`lineRule=auto` 时倍率 = `w:line / 240`

### ABS-C-10 · 首行缩进

- **对象**：中文摘要正文
- **期望**：2 字符
- **判定**：优先读 `w:ind/@firstLineChars`（单位 1/100 字符）；缺失时用 `w:ind/@firstLine ÷ 字号` 换算
- **说明**：`@firstLineChars` 是"字符数"的权威表达，`@firstLine`（缇）是缓存值，两者可能不一致

### ABS-C-11 · 后空行

- **对象**：中文摘要正文最后一段之后
- **期望**：正好 1 个空段落

### ABS-C-12 · 文本

- **对象**：中文关键词——前缀
- **期望**：`关键词：`，冒号为**全角冒号**

### ABS-C-13 · 中文字体

- **对象**：中文关键词——前缀
- **期望**：宋体

### ABS-C-14 · 字号

- **对象**：中文关键词——前缀
- **期望**：小四 = 12pt

### ABS-C-15 · 加粗

- **对象**：中文关键词——前缀
- **期望**：加粗
- **说明**：前缀「关键词：」加粗、内容不加粗，所以关键词行必须**按行内片段**分别判定

### ABS-C-16 · 中文字体

- **对象**：中文关键词——内容
- **期望**：宋体

### ABS-C-17 · 西文和数字字体

- **对象**：中文关键词——内容
- **期望**：Times New Roman
- **判定**：同 ABS-C-07，按字符定位、只判字母与数字

### ABS-C-18 · 字号

- **对象**：中文关键词——内容
- **期望**：小四 = 12pt

### ABS-C-19 · 行距

- **对象**：中文关键词——内容
- **期望**：1.5 倍

### ABS-C-20 · 首行缩进

- **对象**：中文关键词——内容
- **期望**：2 字符
- **判定**：同 ABS-C-10，优先 `@firstLineChars`

### ABS-C-21 · 对齐

- **对象**：中文关键词——内容
- **期望**：两端对齐

### ABS-C-22 · 分隔符

- **对象**：中文关键词——内容
- **期望**：关键词之间用**中文分号** `；`
- **判定**：按 `；` 切分内容，若切分后存在空段或发现其他分隔符（`,` `;` `，` `、`）则报出

### ABS-C-23 · 末尾标点

- **对象**：中文关键词——内容
- **期望**：末尾关键词之后**无标点**
- **判定**：内容的最后一个字符若属于标点（`。` `；` `，` `.` `;` 等）则报出

### ABS-C-24 · 个数

- **对象**：中文关键词——内容
- **期望**：3–5 个
- **判定**：内容按 `；` 切分后计数，不在 3–5 之间则报出

### ABS-C-25 · 存在性

- **对象**：中文摘要区
- **期望**：必须存在**关键词行**（以 `关键词` 开头 + 冒号）
- **判定**：按宽松锚点（文本以「关键词」开头 + 冒号）在中文摘要区内查找；**找不到**即报出
- **报告口径**：`未识别到中文关键词行，请检查是否按「关键词：…」形式书写`
- **说明**：只判"有没有"，不判格式——冒号、加粗、分隔符、个数由 `ABS-C-12~24` 判；识别宽松（`关键词:` 半角冒号也先认下）

## 不做

| 项 | 原因 |
|---|---|
| 摘要字数 ≤300 字 | 规范写了，但属内容规则 |
| 中文摘要标题的行距 | 规范未要求 |
| 中文摘要正文的对齐 | 规范未要求 |
| 关键词行的**位置顺序**（是否在正文之后） | 规范未要求 |

## 来源说明

- **规范文字里有**：标题「三号，黑体，居中，中间空 4 个空格」；正文「小四号，宋体、1.5 倍行距，每段落首行缩进 2 字符，（字母、数字均用 Times New Roman）」；关键词「小四号，宋体，首行缩进 2 字符，'关键词'加粗，与内容之间用冒号'：'，关键词之间用分号'；'，末尾关键词之后不用标点，1.5 倍行距，两端对齐，关键词 3-5 个」；标题 / 正文 / 关键词之间「空一行」
- **取自规范样张**：标题居中、标题后 1 个空段落
- **外部标准**：无
