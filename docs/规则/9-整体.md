## 对象与识别

| 对象 | 识别方式 |
|---|---|
| 顶层模块 | 按各作用域标题的**关键文本**识别（见各作用域文档的「对象与识别」）；不要求空格 / 字体 / 样式正确 |
| 自动编号 | 段落的**有效** `w:numPr`——段落直接属性，或经 `pStyle` 链继承；`numId ≠ 0` 即"使用了自动编号" |
| 分节 | `w:sectPr`（文档级 + 段落级） |
| 页眉 | 分节的 `w:headerReference` 指向的 header 部件 |
| 页脚 | 分节的 `w:footerReference` 指向的 footer 部件 |
| 页码 | 页脚中的 `PAGE` 域；形式读 `w:pgNumType/@fmt` |
| 纸张 / 页边距 | `w:sectPr/w:pgSz`、`w:sectPr/w:pgMar` |
| 独立起页 | 分节符（段落级 `w:sectPr`）、`w:br w:type="page"`、段落 `w:pageBreakBefore` 三者之一 |

## 规则详情

### GLB-26 · 存在性

- **对象**：八个顶层模块（封面 / 中文摘要 / 英文摘要 / 目录 / 正文 / 参考文献 / 致谢 / 附录）
- **期望**：**八个模块全部必填**，必须都能被识别到
- **判定**：按各作用域标题的**关键文本**识别；任一识别不到 → 报出「未识别到 <模块>，请检查标题写法」
- **前置**：在任何作用域规则**之前**跑；**识别不到模块 = 违规**，而不是"该模块的规则不执行"
- **说明**：
  - 模块标题只按"**去空白后的关键文本**"识别——`参考文献`、`附    录`、`摘    要` / `ABSTRACT`、`目    录`、`第X章`…
  - **不要求空格 / 字体 / 样式正确**：写错空格由各作用域的**文本规则**报（如 `REF-01`）；只有**完全识别不到**才由本规则报"缺失"
  - 三态必须分清：`存在且合规` / `存在但写错`（作用域规则报）/ `识别不到`（本规则报）

### GLB-27 · 顺序

- **对象**：八个顶层模块
- **期望**：按 `封面 → 中文摘要 → 英文摘要 → 目录 → 正文 → 参考文献 → 致谢 → 附录` 出现
- **判定**：识别到的模块按出现顺序比对，乱序 → 报出首个乱序位置

### GLB-28 · 禁用自动编号

- **对象**：全文每个段落（正文 / 表格 / 文本框；**页眉页脚不查**）
- **期望**：段落**不使用** Word 自动编号——`第X章`、`[1]`、`（1）` 等编号必须是**手打的文字**
- **判定**：
  - 读段落的**有效** `w:numPr`：段落直接写的，或经 `pStyle` 链继承的
  - `numId ≠ 0` → 报出；`numId="0"`（显式取消编号）→ 不算
  - 逐块报出，并在报告末尾附汇总计数
- **报告口径**：`该段落使用了 Word 自动编号，请改为手动输入编号文字`
- **兜底信号**：文档包里出现 `numbering.xml` 时，在报告末尾附一条提示（可能是残留定义，也可能真有自动编号）
- **依据**：自动编号的**显示文本不在 XML 文本里**（是 Word 排版时生成的），会让所有**文本判定**（`TXT-01`、`REF-10`、`APP-06`…）与**文本识别 / 分区**（`GLB-26` 会误报"缺少模块"）全部失真，须先排除
- **实测**：学校两个规范 docx 均**无 `numbering.xml`**，`styles.xml` 与 `document.xml` 的 `numPr` 均为 **0**
- **不重复报**：命中 `GLB-28` 的段落**不再进入**依赖编号文本的规则（`TXT-19`、`REF-10`、`REF-11`、`APP-06` 等），避免同一条问题报两次

## 跨作用域规则

本作用域多数规则只看单点，但有一类规则**必须看全篇**才能判。它们的**归属与编号不变**（仍写在各自的作用域文档里），**机制**在这里统一约定。

**做法**：在语义层之后、规则之前，构建一次性、只读的 **`DocumentIndex`**（只收集事实，不做判定），跨作用域规则消费它。

| 字段 | 内容 |
|---|---|
| `modules` | 模块 → 块区间 |
| `chapters` | 章号 → 块区间 |
| `floats` | 图 / 表 / 公式登记（章号-序号 → block） |
| `citations` | 正文引用标注：编号集合 + 首次出现顺序 |
| `toc_entries` | 目录条目（层级 / 编号 / 页码文本） |

**需要整篇索引的规则清单**：

| 规则 | 所在文档 | 需要 |
|---|---|---|
| `GLB-26` / `GLB-27` | 9 整体（本作用域） | `modules` |
| `REF-14` / `REF-15` | 6 参考文献 | `citations` |
| `TXT-36` / `TXT-42` / `TXT-48` | 5 正文 | 正文引用文本 + `floats` |
| `TXT-52` | 5 正文 | `chapters` + `floats` |
| `COV-13` | 1 封面 | 区内 5 行（**不跨作用域**，仅需区内聚合） |

**两条纪律**（与 README「通用判定口径」第 8 条同源）：

1. **索引用宽松口径收集，规则负责收缩**——否则"编号写错 → 索引为空 → 连续性规则反而不报"就成了恒真式。
2. **拿不到就显式「无法判定」**——如正文引用抽取失败时，`REF-14` / `REF-15` 输出「无法判定」，不静默通过。

## 不做

| 项 | 原因 |
|---|---|
| 页眉 / 页脚距（`w:header` / `w:footer`） | 规范未要求 |
| 页眉 / 页脚里的图片与域（页码域除外） | 规范未要求 |
| 页眉 / 页脚的「首页不同」「奇偶页不同」 | 规范未要求 |
| 目录页码的正确性 / 连续性 / 与正文一致性、图表跨页、超出版心、行数溢出（属**通道 ②**） | 需渲染产物，本轮 PDF 通道**暂缓** |
