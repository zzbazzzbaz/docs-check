# 4 目录

**作用范围**：**目录区**——从「目    录」标题到 `TOC` 域结束。

## 对象与识别

| 对象 | 识别方式 |
|---|---|
| 目录标题 | 可见文本**去掉内部空白后**等于 `目录` |
| 目录条目 | **`TOC` 域内**、段落样式 **name** ∈ {`toc 1`, `toc 2`, `toc 3`} |
| 一级条目 | 样式 `toc 1` |
| 一级条目（「第X章」型） | 样式 `toc 1` 且可见文本以 `第…章` 开头 |
| 二级条目 | 样式 `toc 2` |
| 三级条目 | 样式 `toc 3` |

**层级判定必须用样式名，两条不能用：**

- 不能用 **styleId**——规范样张里是数字 `9` / `10` / `6`，是任意值
- 不能靠**编号形态**——"参考文献""致    谢""附    录"也是一级条目，但没有"第X章"编号

> **识别锚点要宽松**（见 README「通用判定口径」第 7、8 条）：标题按"去空白后等于 `目录`"匹配；写错空格由 `TOC-01` 报，只有**完全识别不到**才是"缺失"（`GLB-26`）。

## 规则详情

### TOC-01 · 文本

- **对象**：目录标题
- **期望**：`目    录`（「目」与「录」之间**正好 4 个半角空格**）
- **判定**：可见文本逐字符比较
- **说明**：识别锚点须**宽松**（按"去空白后等于 `目录`"匹配），否则空格数写错时会变成"找不到目录标题"，而不是报出本规则

### TOC-02 · 中文字体

- **对象**：目录标题
- **期望**：黑体

### TOC-03 · 字号

- **对象**：目录标题
- **期望**：三号 = 16pt

### TOC-04 · 对齐

- **对象**：目录标题
- **期望**：居中

### TOC-05 · 行距

- **对象**：目录标题
- **期望**：1.5 倍
- **判定**：`lineRule=auto` 时倍率 = `w:line / 240`

### TOC-06 · 后空行

- **对象**：目录标题段之后
- **期望**：正好 1 个空段落
- **判定**：空段落 = 段落内无文字、无图片、无域结果

### TOC-15 · 存在性

- **对象**：目录区
- **期望**：必须至少有 **1 个目录条目**（`toc 1/2/3` 样式的段落）
- **判定**：统计 `TOC` 域内的条目数；**为 0** 时报出
- **报告口径**：`未识别到目录条目，请检查目录是否为「自动生成」的 TOC 域`
- **说明**：
  - 只判"有没有条目"，不判条目层级 / 空格 / 字体——那些由 `TOC-07~14` 判
  - 学生**手工打字**的"目录"（不是 TOC 域）会识别不到 → 报出（规范要求用自动目录）
  - 「目录」模块整个缺失（连「目    录」标题都没有）归 `9-整体` 的 `GLB-26`

### TOC-07 · 中文字体

- **对象**：目录条目（全部层级）
- **期望**：宋体
- **判定**：有效格式。目录条目的 run **通常没有任何字体属性**，全部来自 `toc N` 样式，必须走**样式级联**

### TOC-08 · 西文和数字字体

- **对象**：目录条目（全部层级）
- **期望**：Times New Roman
- **判定**：按**字符**定位——只判 ASCII 字母与数字，读其所在 run 的有效 `ascii` 槽；**排除标点**

### TOC-09 · 字号

- **对象**：目录条目（全部层级）
- **期望**：小四 = 12pt

### TOC-10 · 行距

- **对象**：目录条目（全部层级）
- **期望**：1.5 倍

### TOC-11 · 不加粗

- **对象**：目录条目（全部层级）
- **期望**：非空白字符**不加粗**
- **判定**：只判非空白字符
- **说明**：规范样张的条目是 `'3.1'`（不粗）+ `' '`（**加粗**）+ `'系统结构的设计'`（不粗）。若按"任一 run 加粗"判定，会在规范样张上误报 4 条

### TOC-12 · 编号后空格

- **对象**：一级条目（「第X章」型）
- **期望**：编号与标题之间**正好 2 个半角空格**
- **说明**：规范样张里「第一章  引言」的形式是「第一章」+ 2 空格 +「引言」；判定按可见文本里编号之后、标题首字符之前的空格数

### TOC-13 · 编号后空格

- **对象**：二级条目
- **期望**：编号与标题之间**正好 1 个半角空格**
- **说明**：形如 `2.1 线性表的定义`

### TOC-14 · 编号后空格

- **对象**：三级条目
- **期望**：编号与标题之间**正好 1 个半角空格**
- **说明**：形如 `2.2.1 三级标题名`

## 不做

| 项 | 原因 |
|---|---|
| 一级无编号条目（"参考文献""致    谢""附    录"）的标题内部空格 | 已定不做 |
| 目录页码的正确性、连续性、与正文一致性 | 属通道 ②（需渲染）；本轮 PDF 通道**暂缓** |
| 目录条目的对齐、段间距 | 规范未要求 |
| 目录条目是否含超链接 | 规范未要求 |
| 目录条目包含哪些内容（是否覆盖全部标题） | 需与正文交叉校验，未纳入 |

## 来源说明

- **规范文字里有**：目录标题「三号，黑体，居中，中间空 4 个空格，和正文之间空一行，1.5 倍行间距」；目录条目「编号后空 1 格」「空 2 格」「中间空两格」
- **取自规范样张**：`TOC-07 ~ TOC-11` 这五项不在规范文字里，取自样张的实际格式（宋体 / 小四 / Times New Roman / 1.5 倍 / 不加粗），已确认保留
- **外部标准**：无
