## 对象与识别

| 对象 | 识别方式 |
|---|---|
| 「本科生毕业设计（论文）」行 | 可见文本**去掉内部空白后**等于 `本科生毕业设计（论文）` |
| 题目行 | 可见文本形如 `题…目…：…`，**以全角冒号（含）为界**切分 |
| 题目标签 | 题目行中冒号（含）之前的部分 |
| 题目内容 | 题目行中冒号之后的部分 |
| 信息行 | 行首为 `学生姓名：` / `学    号：` / `院    系：` / `专业年级：` / `指导教师：` 之一 |
| 日期行 | 形如 `年   月   日` |

> **识别锚点要宽松**（见 README「通用判定口径」第 7、8 条）：找对象时不要用严格文本匹配，否则学生写错空格 / 文本时会变成"找不到对象"，而不是**由文本规则报出错误**。

## 规则详情

### COV-01 · 中文字体

- **对象**：「本科生毕业设计（论文）」行
- **期望**：方正小标宋简体
- **判定**：有效格式的中文字体槽（`eastAsia`），走样式级联

### COV-02 · 字号

- **对象**：「本科生毕业设计（论文）」行
- **期望**：小初 = 36pt
- **判定**：有效格式的字号。注意样张里该行有一个**空的 42pt run**，判定须**忽略空的 run**

### COV-03 · 对齐

- **对象**：「本科生毕业设计（论文）」行
- **期望**：居中
- **判定**：段落有效格式的对齐

### COV-04 · 文本

- **对象**：题目标签
- **期望**：`题    目：`
- **判定**：可见文本逐字符比较；「题」与「目」之间**正好 4 个半角空格**，冒号为**全角冒号**
- **说明**：识别锚点须**宽松**（如按"以题…目…：开头"匹配），否则学生把空格数写错时会变成"找不到题目行"，而不是报出本规则

### COV-05 · 中文字体

- **对象**：题目标签
- **期望**：仿宋

### COV-06 · 字号

- **对象**：题目标签
- **期望**：三号 = 16pt

### COV-07 · 加粗

- **对象**：题目标签
- **期望**：加粗
- **说明**：规范文本框只写了"题目：黑体，小二"（指**内容**），标签格式取自规范样张，已确认

### COV-08 · 中文字体

- **对象**：题目内容
- **期望**：黑体

### COV-09 · 字号

- **对象**：题目内容
- **期望**：小二 = 18pt

### COV-11 · 字号

- **对象**：信息行（5 行）

### COV-12 · 加粗

- **对象**：信息行（5 行）
- **期望**：加粗

### COV-13 · 五行格式一致

- **对象**：信息行（5 行）
- **期望**：五行的 **中文字体 / 字号 / 加粗** 三项完全相同
- **判定**：分别取出 5 行的三项有效格式，两两比较；不一致时报出**具体是哪一行、哪一项**
- **说明**：规范原文"学生姓名、学号、院系、专业年级、指导教师**要求一致**"

## 不做

| 项 | 原因 |
|---|---|
| 学校名称格式 | 规范样张里校名是一张**图片**，不是文字，无法判定 |
| 封面分页、封面页码 | 属「9 整体」作用域，已登记为 `GLB-20`（封面单独一页）与 `GLB-11`（封面无页码），本轮纳入 |
| 信息行的对齐、行距、段间距 | 规范未要求 |
| 题目内容的对齐 | 规范未要求 |
| 信息行的标签是否存在、顺序 | 规范未要求；只检查已存在的行 |
